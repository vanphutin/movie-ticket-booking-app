- **Dependencies/trust boundaries:**
  - **Edge Trust Boundary (Client ↔ Gateway):** External client input is untrusted. Gateway validates JWT signatures, strips untrusted headers (e.g. `X-User-Id`), and injects verified internal context.
  - **Service-to-Service Boundary (Gateway ↔ Downstream Microservices):** Microservices trust internal verified context from Gateway but enforce domain-level resource authorization (e.g. Booking verifies customer ownership before hold cancellation).
  - **Database Boundary (Microservice ↔ Local DB):** Microservices interact strictly with their dedicated schema (`ARCH-013`). Cross-service data sharing occurs via REST APIs or Async Outbox Events.
  - **Git Branch Boundary:** Autonomous work unit changes are isolated on `codex/<work-unit>` branches (`CCR-007`).
