# Senior technical capability standard

Mandatory families are web platform, semantic HTML, CSS/layout, JavaScript/browser, TypeScript,
React, component architecture, routing, client state, server state/API, forms, design systems,
accessibility, testing, security, performance, reliability/realtime, observability, delivery,
frontend system design, technical leadership and market adaptability.

Traceability is mandatory:

`market requirement → capability → prerequisite → learning gate → project application → design → coding action → test → evidence → review`.

Readiness dimensions are assessed independently. The curriculum may award
`SENIOR_TECHNICAL_SCOPE_READY`; it must not award a job title or fabricate team/production experience.
