# Frontend learning charter

## Outcome

Learn web engineering from foundations through Senior technical scope while incrementally building
the Movie Ticket Booking frontend against verified backend public APIs.

## Invariants

- Foundation precedes abstraction.
- Every topic maps to a project problem, implementation, test, evidence and review.
- The learner writes primary implementation; Codex teaches, assigns, verifies and reviews.
- A completed feature does not imply Senior readiness.
- `SENIOR_TECHNICAL_SCOPE_READY` requires all mandatory capability dimensions; real-team tenure and
  leadership remain independently observed.
- React + TypeScript + Vite is the application stack. Next.js is outside current scope.
