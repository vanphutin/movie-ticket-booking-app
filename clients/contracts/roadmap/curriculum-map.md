# Frontend curriculum map

The sequence is web/HTTP and semantic HTML; CSS, box model, Flexbox, Grid and responsive design;
JavaScript, DOM, closure, event loop and async; TypeScript strict modeling; React render/state/effect
mental models; class lifecycle literacy; component architecture; routing; Tailwind after CSS;
Redux fundamentals/Toolkit and Zustand after state ownership; TanStack Query after HTTP/race/cache;
forms and Zod; Radix/design system; testing; security; performance; realtime/reliability;
observability/delivery; and Senior system-design/leadership exercises.

Each unit ends in a Movie Ticket artifact and recall occurs again at later integration boundaries.
Backend capabilities and matching frontend weeks alternate only after both sides have verified
handoff evidence.
