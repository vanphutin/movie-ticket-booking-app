# Movie Ticket Booking frontend design language

The visual system is intentionally not selected during control-plane bootstrap. Product-flow and
screen contracts define behavior; this file will later define approved colors, typography, spacing,
elevation, component patterns and do/don't rules. Stitch output is a reviewed visual reference, not
functional or accessibility authority.
